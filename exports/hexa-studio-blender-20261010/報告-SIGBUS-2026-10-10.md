# Blender SIGBUS切り分け（2026-10-10）

## 実施した変更
- scripts/blender-pipeline/pipeline.py：読み込み、縮尺・軸変換、縮尺適用、結合（重複頂点の溶接）、間引き、UV0平面投影、UV1 Smart UV、材質、材質設定後の再投影、AO生成・焼き・保存、GLB出力の前後にSTAGEを即時出力。画像読込・packにも記録を追加。
- 画像読込はcheck_existing=Trueとし、直後にpack。AOは保存先とPNG形式を設定し、packしてからsave。SIGBUSを解消するかは実行待ちで、mmap解放を保証したものではない。
- AO焼き直前にCYCLES・CPU・samples（既定16）を明示。元からあった設定を維持し、samples正数検査を追加。
- UVレイヤー追加後にmesh.update()・validate()。UV1追加後にはUV参照を取り直す。
- --skip-ao：AO画像・AOノード・焼き・保存を省略。UV1 Smart UVは実行するため、UVとAOの切り分けが可能。GLBを出す場合はAOなしの確認用。
- --skip-export：GLBを作らずmetrics.jsonを保存（bytes=null）。両方の引数を併用可能。省略した段階はSKIPで記録。
- run.py：両引数をBlender側へ渡す。標準出力と標準エラーを合流し、blender-run.logへ逐次保存。終了コードも末尾に保存する。
- 作業場とexports/hexa-public/scripts/blender-pipelineの3ファイルを一致させた。変更前はbefore-sigbus/に保存。

## ジョブズが順に試すコマンド3本

作業場の直下で、1本ずつ実行する。各行の出力先は別名。再試行時は末尾の番号を変える（既存フォルダは上書きせず停止）。

### 1. 全部
```sh
python3 -B scripts/blender-pipeline/run.py exports/hexa-studio-blender-20261010/input-floor/interior-floor-oak.mesh.json exports/hexa-studio-blender-20261010/out-sigbus-full-1 --finish oak --tile-mm 300 900 --tiles exports/hexa-studio-blender-20261010/tiles
```

### 2. AOなし
```sh
python3 -B scripts/blender-pipeline/run.py exports/hexa-studio-blender-20261010/input-floor/interior-floor-oak.mesh.json exports/hexa-studio-blender-20261010/out-sigbus-no-ao-1 --finish oak --tile-mm 300 900 --tiles exports/hexa-studio-blender-20261010/tiles --skip-ao
```

### 3. AOもGLB書き出しもなし
```sh
python3 -B scripts/blender-pipeline/run.py exports/hexa-studio-blender-20261010/input-floor/interior-floor-oak.mesh.json exports/hexa-studio-blender-20261010/out-sigbus-no-ao-no-export-1 --finish oak --tile-mm 300 900 --tiles exports/hexa-studio-blender-20261010/tiles --skip-ao --skip-export
```

## 記録の見方
各出力先直下のblender-run.logを比較する。BEGINと同名のENDが揃っていない最後の段階が停止候補。SIGBUSではPythonのERROR行が出ない場合がある。
1だけ失敗ならAO関連が候補、1・2が失敗して3が成功ならGLB出力が候補。3でも失敗する場合は読み込み・画像pack・形状・UV・材質の最後のSTAGEを確認。これは候補の絞り込みであり原因確定ではない。
